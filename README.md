
# Marketing Campaign Analytics Dashboard

**A Data Analytics Project using Excel, SQL, and Power BI**

## Project Overview

Marketing Campaign Analytics is a data analytics project focused on understanding customer behavior, evaluating marketing campaign performance, and identifying customer segments.

The project uses Excel for data preparation and analysis, MySQL for querying customer data, and Microsoft Power BI to build an interactive dashboard that presents key performance indicators (KPIs) and customer insights.

## Objectives

- Analyze customer responses to marketing campaigns.
- Compare acceptance rates across five marketing campaigns.
- Measure overall campaign response and acceptance performance.
- Segment customers based on customer value.
- Analyze customer distribution by country and age group.
- Present business insights through an interactive dashboard.

## Tools and Technologies

| Tool | Purpose |

## Dashboard Preview

The Power BI dashboard provides an overview of marketing campaign performance and customer demographics.

**Dashboard components:**
- KPI cards for total customers, response rate, campaign acceptances, and total responses.
- Campaign acceptance rate comparison.
- Customer segmentation by value.
- Customer distribution by country.
- Customer distribution by age group.
- Interactive country filter.

## Key Findings

- **Customer demographics:** The 46–60 age group is the largest age group in the current dataset, with 1,030 customers.
- **Customer segmentation:** The Low Value segment contains the largest number of customers, with 1,026 customers.
- **Campaign performance:** Campaign acceptance rates vary across the five campaigns, making campaign-level comparison useful.
- **Geographic distribution:** Spain has the highest customer count in the current dashboard, with 1,095 customers.

These findings describe the current dashboard and do not, by themselves, establish the causes of campaign performance.
